# 🧮 Calculadora de Orçamento Pessoal

Este é um projeto desenvolvido como parte do meu portfólio, com o objetivo de aplicar conceitos fundamentais de **desenvolvimento front-end** utilizando React.

## 🚀 Objetivo
Permitir que o usuário registre despesas e visualize um resumo mensal, auxiliando no controle financeiro pessoal.

## 🛠️ Tecnologias utilizadas
- React  
- JavaScript (ES6+)  
- HTML5  
- CSS3  

## 📚 O que aprendi
- **Gerenciamento de Estado**: utilização do hook `useState` para controlar dados de forma reativa.  
- **Componentização**: criação e reutilização de componentes para a interface.  
- **Props**: passagem de dados e funções entre componentes (pai → filho).  
- **Renderização Condicional**: exibição de diferentes partes da interface com base no estado.
