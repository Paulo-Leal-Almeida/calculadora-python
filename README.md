# 🧮 Calculadora Simples em Python

Este é um projeto de **calculadora simples** desenvolvida em **Python**.  
O objetivo é permitir que o usuário realize operações matemáticas básicas de forma rápida e prática via **terminal**.

---

## 🚀 Funcionalidades
- ➕ **Adição**  
- ➖ **Subtração**  
- ✖️ **Multiplicação**  
- ➗ **Divisão** (com tratamento para evitar divisão por zero)  
- ❌ Encerrar o programa digitando **"sair"**

---

## 🛠️ Tecnologias Utilizadas
- **Python 3.x**

---

## 📚 O que aprendi
- **Entrada e saída de dados**: uso da função `input()` para coletar dados do usuário e `print()` para exibir resultados.  
- **Laços de repetição**: utilização de `while True` para manter o programa em execução contínua.  
- **Tratamento de erros**: uso de `try/except` para capturar entradas inválidas e evitar falhas no programa.  
- **Condicionais**: implementação de estruturas `if/elif/else` para controlar a lógica das operações matemáticas.  

---

## ▶️ Como executar
1. Certifique-se de ter o **Python 3** instalado em sua máquina.  
2. Baixe o arquivo `calculadora.py`.  
3. No terminal, navegue até a pasta onde o arquivo está salvo.  
4. Execute o comando:  

```bash
python calculadora.py
